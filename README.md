# Incident Platform

An incident platform that detects failures and tracks them.
Everything runs on Kubernetes (k3s) and AWS, provisioned with Terraform.

I'm bulding this project to improve my platform engineering skills.

## Roadmap
- [ ] Infrastructure: VPC, EC2, RDS with Terraform
- [ ] Backend: FastAPI + PostgreSQL
- [ ] CI/CD, Helm, ArgoCD, monitoring
- [ ] AI agent that analyzes logs and diagnoses incidents
